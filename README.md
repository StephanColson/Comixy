Project:
Een strip catalogus om strips, reeksen en edities te beheren.

Functionaliteiten:
- Serie tab: toont een lijst van de series dat strips bevatten van die specifieke serie.
- Comic tab: toont een lijst van alle strips dat in de database zitten.
- Add Comics tab: is the formulier om een nieuwe strip te maken of een nieuwe editie maken.
- Home pagina: heeft een carousel die toont the 5 nieuwste toegevoeged editie.

Technologie:
- Firebase (database)
- Supabase opslag voor de afbeeldingen (later Cloudflare R2)
- React (hoofd-framework)
